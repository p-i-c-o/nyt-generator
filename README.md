Generates links for the NewYorkTimes Mini Crosswords

Instead of paying for the NYTimes minis archive, I made a simple UI to generate a link for each and every mini available.

## Installation
You can download the latest stable version [here](https://github.com/p-i-c-o/nyt-generator/releases/tag/stable), or by opening the releases tab.

> _(14/04/2025) Only **linux-deb** version available_

## Build locally
1. If you'd prefer building locally, open the project using **NetBeans** (that's how I build it) and build a ``.jar`` using the hammer icon.
2. Configure the ``build.sh`` script and run it to build a **DEB** installer.
